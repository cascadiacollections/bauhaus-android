These remain the property of Kevin T. Coughlin and may not be used to name, brand, or market a
fork or derived product without written permission.

## What you can do freely

- Fork, modify, build, and redistribute the code under its license —
  **under a different app name, icon, and application ID**
- Build and install the app from source for yourself, unchanged, including its name and icon
- Distribute unmodified builds through F-Droid and similar repositories that build from this
  source
- Use the name "Bauhaus" nominatively: to refer to this project in articles, reviews,
  compatibility notes ("based on Bauhaus"), and attribution

## Why

This is the standard FOSS arrangement (used by Firefox, VLC, and many others): the code is free,
the identity is not. It protects users from confusing or misleading clones — including
repackaged copies sold on app stores — without restricting any freedom the license grants.

# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Bauhaus, please report it through [GitHub's private vulnerability reporting](https://github.com/cascadiacollections/bauhaus-android/security/advisories/new).

Do **not** open a public issue for security vulnerabilities.

## Supported Versions

Only the latest release is supported with security updates. The app has no public Google Play listing; builds are published on [GitHub Releases](https://github.com/cascadiacollections/bauhaus-android/releases).

Bauhaus

A daily artwork wallpaper app for Android.

Download nightly APK

A signed FOSS build for early adopters. Updated daily and after changes to the app. You may encounter bugs.

Try it on your phone

  1. Download the nightly APK and open it on your Android device.
  2. When Android asks, allow your browser or file manager to install unknown apps.
  3. Install and open Bauhaus. Use the same download button for future updates.

Nightlies use the same signing key so you can update without uninstalling. Switching from a store or locally signed build may require uninstalling first, which removes local app data.

Help shape Bauhaus

Report a bug or share feedback. Include your device model, Android version, and what happened.
